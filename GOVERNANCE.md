# Governance

EN MOSTAFA AI AGENT is currently maintained by Mostafa Selim Farag under a benevolent-maintainer model.

- Technical decisions are discussed in public issues before major implementation work.
- Security-sensitive changes require a threat-model note and tests.
- Contributions are judged on correctness, safe defaults, Windows compatibility, maintainability, and user impact.
- The maintainer may appoint additional reviewers as sustained contributors emerge.
- Governance will be revisited when the project has three or more regular external contributors.
