# Roadmap

## Next security milestone

- Token-based authentication and scoped permissions.
- Path allowlists and command policy enforcement.
- Structured audit log with secret redaction.
- Safer subprocess execution without shell interpolation where possible.

## Runtime milestone

- Merge REST and MCP lifecycle management.
- Replace embedded dashboard HTML with a maintainable frontend package.
- Persist jobs and recover interrupted work.
- Add integration tests for Playwright and REST tools.

## Intelligence milestone

- Define stable interfaces for planner, strategy, monitoring and memory engines.
- Restore missing internal cognition modules or replace them with provider-neutral adapters.
- Add approval gates for destructive actions and dependency installation.
- Measure recovery strategies with reproducible evaluation tasks.

## Distribution milestone

- Windows service packaging.
- Signed executable installer.
- Docker support for non-Windows browser-only operation.
- Versioned configuration migration and release artifacts.
