# Security Policy

## Supported version

Security fixes target the newest public-preview branch.

## Critical trust boundary

When `READONLY_MODE=false`, this agent can create files, create directories and execute shell commands with the permissions of the account running it. Browser tools can also interact with authenticated sessions. Treat every connected MCP client as a trusted local administrator.

## Safe deployment rules

1. Keep `REST_HOST` and `MCP_HOST` set to `127.0.0.1`.
2. Keep `READONLY_MODE=true` until power tools are explicitly required.
3. Never commit `.env`, tokens, cookies, browser profiles, databases, screenshots or logs.
4. Run under a non-administrator Windows account whenever possible.
5. Do not expose ports 5001 or 8000 directly to a LAN or the internet.
6. If remote access is required, place the services behind authenticated TLS access and an allowlist. A tunnel alone is not authentication.
7. Review every command generated by an untrusted model or prompt source.

## Reporting a vulnerability

Do not open a public issue containing exploitation details, secrets or user data. Contact the maintainer privately through the contact method listed on [devmostafa.com](https://www.devmostafa.com). Include the affected version, impact, reproduction steps and a minimal proof of concept.
